BẢNG ĐIỀU KHIỂN KHỞI CHẠY

Điều khiển, sao chép lệnh khởi chạy và quản lý trọn bộ hệ thống SportShop Microservices

⚙️ Bước 1: Khởi Động Cơ Sở Hạ Tầng (Docker)

Chạy các lệnh Docker dưới đây trong Terminal để kích hoạt các dịch vụ đệm và hàng đợi tin nhắn trước khi bật Backend.

1 Khởi động RabbitMQ Broker (Topic Exchange)
docker run -d --name rabbitmq-sportshop -p 5672:5672 -p 15672:15672 rabbitmq:3-management
2 Khởi động Redis Cache (RAM Cache)
docker run -d --name redis-sportshop -p 6379:6379 redis:alpine
3 Lệnh dọn sạch Cache Redis cũ (Khi cần làm sạch dữ liệu)
docker exec -it redis-sportshop redis-cli flushall

☕ Bước 2: Biên Dịch & Chạy Backend Microservices

Khuyến nghị: Bạn nên mở dự án bằng IntelliJ IDEA, Rebuild dự án bằng Ctrl + F9, sau đó click nút Run cho từng Service theo thứ tự từ 1 đến 6. Nếu chạy bằng Terminal, di chuyển vào từng thư mục và chạy lệnh:

mvn spring-boot:run
Tên Dịch Vụ Cổng Port Trạng Thái Hành Động / Đường dẫn
1. AuthService 8081 Online Xác thực & Bảo mật
2. ProductService 8082 Online Sản phẩm & Cache
3. OrderService 8083 Online Đơn hàng & Giỏ hàng
4. PaymentService 8084 Online Thanh toán
5. AIService 8085 Online Trợ lý AI Gemini
6. ChatService 8086 Online Microservice Chat (In-Memory)
7. GatewayService 8080 Online Bật cuối cùng!

⚛️ Bước 3: Khởi Chạy React Frontend

Mở Terminal mới, di chuyển vào thư mục `shop-sport` để chạy giao diện cửa hàng.

1 Di chuyển vào thư mục React
cd d:\Nam4\KTTKPM\Project\shop-sport
2 Khởi chạy Frontend Dev Server
npm run dev
